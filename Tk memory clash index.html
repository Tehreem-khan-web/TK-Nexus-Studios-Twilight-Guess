# Twilight Guess 🎯 An interactive number guessing game built with HTML, CSS, and JavaScript. ## 🎮 Features - Single Player mode - Local Duel mode - Multiple difficulty levels - Timer Sprint mode - Attempt tracking - Game history - Leaderboard - Achievements - Animated twilight-themed interface - Local progress and high-score storage ## 🛠️ Technologies Used - HTML5 - CSS3 - JavaScript - Browser Local Storage ## 🎯 About the Project Twilight Guess is a browser-based number guessing game designed to make a simple guessing game more interactive through different game modes, difficulty levels, scoring, achievements, and an animated user interface. ## 🚀 How to Run Open `TK Nexus Studios.html` in a modern web browser and start playing. ## 👩‍💻 Author Tehreem Khan
